Spotify setup

  1. Open the Spotify Developer Dashboard and create an app.
  2. Open the app's Settings and add the Redirect URI shown below.
  3. Copy the app's Client ID and Client Secret into the required fields.
  4. Click Save Config, then click Connect Spotify and approve access.

YouTube Music Desktop setup

  1. Install and sign in to the required YouTube Music Desktop app.
  2. Keep the desktop app running on the same computer as OBS.
  3. Click Connect YouTube Music below and approve the connection code in the desktop app.
  4. Keep the app open while using the widget. Playback updates arrive in real time through the local connection.

A Google API key is not required. This connection reads playback state from the desktop app running locally.
