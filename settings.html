Spotify setup

  1. Open the Spotify Developer Dashboard and create an app.
  2. Open the app's Settings and add the Redirect URI shown below.
  3. Copy the app's Client ID and Client Secret into the required fields.
  4. Click Save API Keys, then click Connect Spotify and approve access.

YouTube Music setup

  1. Open Google Cloud Console and create or select a project.
  2. Open APIs & Services > Library, search for YouTube Data API v3, and click Enable.
  3. Open APIs & Services > Credentials and choose Create Credentials.
  4. When Google asks What data will you be accessing?, choose Public data, not User data, then click Next. User data starts an OAuth setup and is not needed here.
  5. Finish creating the API key, copy it into the field below, and click Save API Keys.

For security, restrict the key to YouTube Data API v3. This key is optional and is only needed for YouTube or YouTube Music metadata.
